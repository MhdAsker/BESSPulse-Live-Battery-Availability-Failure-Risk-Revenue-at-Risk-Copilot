# Changelog

## 1.0.0 - 2026-10-09

- Added configurable BESS simulation, deterministic fault injection, and provenance-safe storage.
- Added secure ENTSO-E DE-LU ingestion and causal feature engineering.
- Added expected-behavior, delivery-risk, anomaly, and price forecasting experiments.
- Added deterministic availability, CVXPY Revenue-at-Risk, and transparent alerts.
- Added typed FastAPI and ten-page Streamlit operations dashboard.
- Added approved-document RAG, MLflow adapters, and model/data monitoring.
- Added PostgreSQL/Alembic hardening, Docker images, CI/CD workflows, production configuration validation, safe system metadata, and deployment documentation.

Known limits: telemetry/model validation remains simulated, 24-hour risk calibration is limited, authentication is absent, pgvector is not implemented, and the Prompt 13 Gemini operational agent is not present.
